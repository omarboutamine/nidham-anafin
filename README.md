# Nidham Anafin

Plateforme d’**analyse financière** destinée aux **étudiants et chercheurs** universitaires.

## Démarrage

```bash
cd "%USERPROFILE%\Desktop\nidham-anafin"
npm run dev
```

Ouvrir : http://localhost:5140

## Déjà en place

- Page d’accueil (identité visuelle proche de SAF / Nidham)
- AR / FR
- Création de compte avec **upload de la carte étudiant** (stockage local pour l’instant)
